## Cardioid Condenser Microphone

The Beta 98A is a revision of the company’s Beta 98, also a miniature cardioid condenser microphone intended for instrumental miking applications. The mic was introduced at the AES show in late 2010, as part of a revamp of the entire Beta product line.

Like the original, the Beta 98A has a two-piece design. The capsule head is small, which allows easier positioning in a studio context as well as making the microphone less visible on stage. The microphone’s amplifier circuitry is housed separately, and can be located up to 25 feet from the capsule head.

The “A” revision of the Beta 98 incorporates a new electret capsule design, which brings higher sensitivity and lower self-noise:

|  |  |  |
| --- | --- | --- |
|  | **Sensitivity** | **Self-Noise** |
| **Beta 98** | 1 mV/Pa | 35 dBA |
| **Beta 98A** | 4 mV/Pa | 30 dBA |

The 98A revision does not incorporate a new amplifier circuit. The included inline preamplifier for the 98A is identical to the one used for the Beta 98. Both connect to their respective capsule heads via Shure’s “TQG” cable (included with the mic).

Note that the Beta 98AMP’s integrated preamplifier differs in sound and specifications from the Beta 98 / Beta 98A inline preamplifier. The original Beta 98 preamp design was revised and improved during the 98AMP design process.

> John Born, Shure
>
> The only difference between the Beta 98A/C and Beta 98AD/C is the included hardware. The AD/C versions come with the drum mount, [whereas] the /C version comes with a swivel mic stand mount. Both include the external preamp and new capsule design.

The mic includes a zippered pouch (Shure p/n 95A2314), an in-line preamplifier (p/n RPM626), and a snap-on windscreen (p/n 95A2064). Included mounting hardware varies by model:

|  |  |
| --- | --- |
|  | **Includes** |
| **Beta 98A/C** | Shock-mount swivel adapter (p/n RK282) |
|  | Lightweight 25ft cable (p/n 95A2398) |
| **Beta 98AD/C** | Drum mount (p/n A98D) |
|  | Heavy-duty 15ft cable (p/n C98D) |
