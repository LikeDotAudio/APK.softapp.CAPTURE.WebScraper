## Blue Microphones Blue Drum Kit Kit

## 3-Mic Set

The Blue Drum Kit Kit packages three of Blue’s signature condenser microphones into a 3-mic set for drum kit:

* Two Dragonfly mics for overheads
* One Mouse for kick drum

The set includes shockmounts for all three mics, and ships in a padded aluminum flightcase.
