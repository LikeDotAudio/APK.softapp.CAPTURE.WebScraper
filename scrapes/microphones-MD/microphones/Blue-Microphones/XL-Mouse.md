## Cardioid Condenser Microphone

The XL Mouse was a transformerless version of BLUE’s Mouse microphone. Both mics used Blue’s proprietary 34mm large-diaphragm capsule mounted within a unique swiveling head assembly.

Blue ascribed no sound or performance differences to the XL version of the microphone, although we suspect from the following description that the transformerless version had higher output impedance.

> BLUE
>
> The Mouse is available with two different output circuitries — transformer [or] transformerless. The main difference between these designs is that the transformer-based Mouse allows the user the option to run extra long mic cables for special applications and provides the user with the utmost protection for outside interference such as radio type frequencies (RF). These models are also designated by their difference in body color. The transformer version is styled in matte black while the transformerless is finished in a dark royal blue.

The XL Mouse was discontinued around 2002.
