## Miktek PMD4

## 4-Mic Set

The PMD4 is a 4-mic set of drum kit mics. It contains three of Miktek’s PM10 dynamics for toms and snare, and one PM11 for kick drum. All four mics have integrated hard mounts; the PM10s include detachable rim clamps for mounting on snare and tom hoops.

Both the PM10 and PM11 use a custom-designed capsule with a frequency response contoured for drum reproduction. Both use output transformers from AMI.

The kit ships in a padded aluminum flightcase.
