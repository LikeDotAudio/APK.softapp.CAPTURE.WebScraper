## Audix DP Elite 8

## 8-Mic Set

The DP Elite 8 is an 8-piece drum mic package with some of Audix’s top mics. It is nearly identical to the Studio Elite 8 kit, swapping the large-diaphragm overhead mics in the Studio kit for a pair of pencil mics in the DP kit.

This set includes:

* One D6 for kick drum
* One i5 for snare drum
* Two D2 for rack toms
* One D4 for floor tom
* Two SCX1 with Cardioid capsules for overheads
* One SCX1 with Hypercardioid capsule for hi-hat

The SCX-1 is a pencil mic with detachable capsules. This kit includes three, two with cardioid capsules and one with hypercardioid capsule.

![Audix DVice gooseneck rim clamp](http://cdn.recordinghacks.com/images/mic_extras/audix/dvice.jpg)Four DVICE mounts are included. The DVICE is an adjustable rim mount, with a gooseneck arm to facilitate mic positioning. The DVICE includes the DCLIP, a rigid plastic clip engineered to tightly grip the end of the D2/D4/D6 body.
