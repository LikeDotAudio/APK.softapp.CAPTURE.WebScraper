## Audix DP5A

## 5-Mic Set

The Audix DP5A is a 5-piece drum mic package with 5 dynamic mics, mounts and a foam-lined aluminum case.

The set includes:

* One D6 dynamic for kick drum, with DCLIP hardmount
* One i5 dynamic for snare drum, with DVICE gooseneck rim-mount
* Two D2 dynamics for rack toms, with DVICE gooseneck rim-mounts
* One D4 dynamic for floor tom, with DVICE gooseneck rim-mount

Most users would pair the DP5A with one or two overhead condenser microphones, resulting in a kit that would be suitable for stage or studio.
