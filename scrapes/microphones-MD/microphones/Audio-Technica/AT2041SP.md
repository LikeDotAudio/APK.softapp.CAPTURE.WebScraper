## Audio-Technica AT2041SP

## Stereo Mic Set

The Audio-Technica AT2041SP is a low-cost set of two electret condenser microphones for home and project studio use.

This “Studio Pack” includes:

* AT2020 Side-address cardioid condenser microphone, with hard mount
* AT2021 Small-diaphragm cardioid condenser microphone, with clip
* SONAR LE recording software
* Two protective pouches
