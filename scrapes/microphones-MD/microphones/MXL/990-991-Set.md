## MXL 990 991 Recording Set

## Stereo Mic Set

The MXL 990/991 is one of the most popular recording microphone bundles on the market. It consists of a single MXL 990 side-address condenser, and an MXL 991 pencil mic.

Both mics include hard mounts (the MT-001 ring mount for the 990, and the plastic H-03 clip for the 991). No other accessories are included, save the padded plastic carrying case.
