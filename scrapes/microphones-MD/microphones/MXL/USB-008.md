## Cardioid Condenser Microphone

MXL’s USB.008 is a large-diaphragm FET condenser mic with a built-in analog-digital converter.

The ADC is capable of 16-bit, 48-kHz output. Users can select a 44.1 kHz sample rate via software on the host computer.

The mic has a USB port on its base, and is designed to plug directly into a Windows PC or Mac without using an external preamp.

In lieu of a more-traditional pad, the USB.008 has a 3-way gain reduction switch, which attenuates the analog signal before digital conversion. The switch is not calibrated; the legend reads “hi,” “med,” “lo.”

The USB.008 ships with a foam windscreen, a hard mount (MXL p/n MXL MT-001), a 10' USB cable, and a carrying case that looks like a man-purse.

MXL’s newer USB “broadcast” mic, the USB.009, uses a similar 32mm OD capsule, but its ADC can deliver 24-bit, 96kHz conversion. The .009 also has a headphone jack for zero-latency monitoring and a DAC for monitoring recorded tracks and/or multitracking.

The [MXL USB.008](//recordinghacks.com/microphones/MXL/USB-008) is also known as: USB008, .008, USB 008.
