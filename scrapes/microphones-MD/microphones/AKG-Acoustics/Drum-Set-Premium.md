## AKG Acoustics Drum Set Premium

## 8-Mic Set

The “Drum Set Premium” from AKG is an 8-piece microphone set. Included are four D40 dynamics for snare and tom, with K&M24030 rim clamps. The C451 (aka C 451 B) cardioid electret pencil mic is included for hi-hats. The kick mic is AKG’s D12 VR, a dynamic mic with phantom-powered EQ circuitry. Two matched C 214 large-diaphragm condensers are supplied for overheads.

The kit ships in a “heavy duty” metal case, photos of which have not been made available.
