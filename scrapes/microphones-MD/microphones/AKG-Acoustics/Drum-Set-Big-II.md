## AKG Acoustics Drum Set Big II

## 7-Mic Set

The Drum Set Big II is a 7-piece microphone set intended primarily for stage, rather than studio miking.

The kick drum mic is AKG’s venerable D112. Overheads are the latest redesign of the C1000S pencil condenser. THe snare and tom mics (4 in all) are miniature electret C518 condensers, with built-in rim clamp mounts.

The kit ships in a compact flightcase.
